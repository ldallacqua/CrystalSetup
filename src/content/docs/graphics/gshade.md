## GShade Documentation

GShade provides post-processing effects to enhance the game's visuals.

### Installation
1. Download the latest installer from the official repository.
2. Point it to your `ffxiv_dx11.exe`.

### Optimization
- Disable heavy shaders like ADOF during combat.
- Use the **Performance Mode** checkbox in the GShade UI.
