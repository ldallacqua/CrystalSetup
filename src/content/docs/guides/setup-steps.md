## Setup Guide

Follow these steps in order to replicate the CrystalSetup.

### Step 1: Clean Installation
- Install FFXIV.
- Run the game once to generate configuration files in `Documents/My Games`.

### Step 2: Driver Configuration
- Install the latest NVIDIA Game Ready Driver.
- Apply settings from the [NVIDIA Settings](/graphics/nvidia-settings/) page.

### Step 3: Graphics Tweaks
- Configure [DLSS](/graphics/dlss-configs/) settings.
- Install [GShade](/graphics/gshade/).

### Step 4: Software & Mods
- Setup [Dalamud](/software/dalamud-plugins/).

### Step 5: In-game Settings
- Resolution: Native.
- Graphics Preset: Maximum (with DLSS adjustments).
