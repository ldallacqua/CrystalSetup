This section covers the mods, plugins, and launcher tooling that surround the graphics configuration described in the rest of this guide. Some pages are written; others are placeholder topics that will fill in over time.

## Currently Documented

- **[XIVLauncher](/CrystalSetup/mods/xivlauncher/)** — open-source FFXIV launcher with secure auto-login, **DPI-awareness fix** (critical on high-DPI displays so the graphics setup actually pays off), faster patch downloads, and the Dalamud plugin framework.

### GPose tools

- **Ktisis** and **Brio** — advanced character posing and scene staging tools for GPose.

### ACT & combat tools

- **Cactbot** setup for raid triggers and fight timelines.
- **FFLogs** integration for combat logging and performance analysis.

:::note[Client-Side Only]
All mods and plugins covered in this section are client-side only and do not affect other players. Square Enix's official position on third-party tools is nuanced — see the community resources for the current state of enforcement before proceeding.
:::
